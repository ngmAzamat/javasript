Деструктурицая Массива:

Было:

const arr = ["Александр", 28]
const name = arr[0]
const age = arr[1]
console.log("name: ", name)
console.log("age: ", age)

Стало:

const arr = ["Александр", 28]
const [ name, age ] = arr
console.log("name: ", name)
console.log("age: ", age)
